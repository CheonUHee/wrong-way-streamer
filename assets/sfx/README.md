# 효과음 출처

녹음 소리(*.ogg)는 모두 [Kenney](https://kenney.nl)의 무료 에셋(CC0, 표기 의무 없음)에서 골라 이름을 바꿨다.

| 묶음 | 쓴 파일(이 폴더 이름 ← 원본) |
|---|---|
| Interface Sounds | chat_send ← drop_002, dona_mine ← confirmation_002, dona_troll ← error_006, button ← switch_002, pluck ← pluck_001 |
| RPG Audio | coins1·2 ← handleCoins·2, door_open ← doorOpen_1, door_rattle ← doorClose_3, lever_latch ← metalLatch, creak·creak_low ← creak2·3, use_item ← metalClick, cloth1~4, sword ← drawKnife1 |
| Impact Sounds | step_wood·grass·stone0~4 ← footstep_wood·grass·concrete_000~004, metal0~2 ← impactMetal_light, poke·wood1~3 ← impactWood_light·medium, stone_hit·2 ← impactMining_000·001, thud ← impactSoft_heavy_000, plank ← impactPlank_medium_000 |

코드로 만드는 소리(바위·통 굴러옴, 자갈, 불, 철문 긁힘, 채팅 읽음·놓침, 클리어 팡파르(현 녹음으로 연주), 오리, 용수철, 한별 웅얼거림 등)는 `js/sfx.js`에 있다.
`.ogg`는 Chrome·Edge·Firefox에서 재생된다. Safari는 지원이 불안정하다.
