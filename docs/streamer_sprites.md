# 한별 표정 이미지 제작 지침(ChatGPT 요청용)

게임 화면 오른쪽 아래, 웹캠 자리에 들어갈 스트리머 '한별'의 표정 연속 이미지입니다.
아래 `공통 지침`을 첫 메시지에 붙여 넣고, 그다음 감정별 블록을 하나씩 요청하세요.

---

## 0. 작업 순서(중요)

이미지 생성 AI는 같은 캐릭터를 여러 장 그리면 얼굴·옷·크기가 조금씩 달라집니다. 그래서 아래 순서로 요청합니다.

1. **기준 이미지 1장**을 먼저 만듭니다(`normal` 1번). 마음에 들 때까지 다시 뽑습니다.
2. 감정마다 **대표 장면(키 프레임) 1장**을 기준 이미지를 첨부해서 만듭니다.
3. 나머지 장은 **바로 앞 장을 첨부하고 "이 그림에서 ○○만 바꿔 줘"** 식으로 고쳐 만듭니다. 처음부터 새로 그리게 하지 않습니다.
4. 받은 그림은 `assets/streamer/<감정>/1.png, 2.png …`로 저장합니다. 크기 맞추기(1000×1200 자르기)·위치 정렬·용량 줄이기는 받은 뒤 일괄 처리합니다.

---

## 1. 공통 지침(첫 메시지에 붙여 넣기)

```
게임에 들어갈 캐릭터 표정 연속 이미지(스프라이트)를 여러 장 만들 거야. 아래 조건을 모든 그림에 똑같이 지켜 줘.

[캐릭터]
- 이름: 한별. 인터넷 방송을 하는 중학생 나이대 스트리머.
- 성격: 호기심이 엄청 많고 덤벙대는 4차원. 귀여움과 보이시함이 섞인 중성적인 분위기.
- 머리: 연두색(#D3E7A5) 머리. 
- 피부: 밝은 살구색(#FFE7DA).
- 눈: 짙은 보라 갈색(#3A2A4A).
- 옷·소품: (직접 정해서 채우기. 예: 헐렁한 후드티, 게이밍 헤드셋)

[구도]
- 방송 웹캠 화면처럼 가슴 위까지 나오는 상반신(버스트 샷).
- 몸은 정면에서 살짝 왼쪽을 향한 3/4 각도. 시선은 기본적으로 화면 정면~살짝 왼쪽.
- 몸 아래쪽(가슴)은 이미지 아래 끝에서 잘리게 꽉 채운다.
- 이미지 위쪽 20%는 비워 둔다(나중에 위를 잘라 5:6 비율로 쓴다). 머리카락 끝·감정 표시(땀방울, 분노 마크 등)도 위쪽 20% 안으로 들어가지 않게.
- 모든 장에서 캐릭터 크기와 위치가 같아야 한다. 움직임은 표정·고개·어깨 정도로 작게.

[그림 형식]
- 세로형 1024×1536, 배경 완전 투명(PNG). 바닥 그림자·테두리·배경 장식 없음.
- 깔끔한 2D 애니메이션 셀 채색, 굵고 깨끗한 외곽선. 화면에서 약 300px로 작게 보이므로 표정이 작게 봐도 읽혀야 한다.
- 글자, 말풍선, 워터마크는 넣지 않는다.
- 모든 장의 조명·채색·선 굵기를 똑같이.

이해했으면 먼저 기준 이미지(normal 1번)부터 그려 줘.
```

## 2. 감정별 요청

재생 속도는 **초당 8장**입니다. 8장이면 1초, 4장이면 0.5초짜리 동작입니다.
`반복`은 그 표정이 화면에 있는 동안 계속 돌고, `한 번`은 끝까지 재생한 뒤 마지막 장에서 멈춥니다.

### normal(평소) · 그림 4장 · 반복

화면에 가장 오래 나오는 기본 표정입니다. 숨 쉬기와 눈 깜빡임만 있는 잔잔한 대기 동작입니다.

| 장 | 내용 |
|---|---|
| 1 | 기준 그림. 입을 살짝 다문 편한 미소, 눈 뜸, 호기심 있는 눈빛 |
| 2 | 1번에서 어깨·머리가 아주 살짝(몇 픽셀) 위로. 숨을 들이쉰 느낌 |
| 3 | 1번에서 눈만 반쯤 감음 |
| 4 | 1번에서 눈만 완전히 감음 |

- 재생 순서는 `1 1 2 2 1 1 3 4 3 1 …`처럼 깜빡임이 가끔 나오게 이쪽에서 맞춥니다(같은 그림은 파일 복사).

```
방금 만든 기준 이미지(normal 1번)를 바탕으로 normal 2~4번을 한 장씩 만들어 줘. 구도·크기·위치는 1번과 완전히 같게, 바뀌는 부분만 바꿔.
- 2번: 어깨와 머리가 아주 살짝 위로 올라간 숨 들이쉬는 순간
- 3번: 눈만 반쯤 감은 상태
- 4번: 눈만 완전히 감은 상태
```

### happy(기쁨) · 그림 6장 · 반복(0.75초)

"오케이, 레츠 고!" 같은 신나는 순간. 들뜬 리듬으로 몸이 통통 튑니다.

| 장 | 내용 |
|---|---|
| 1 | 눈웃음(초승달 눈), 입을 크게 벌린 웃음 |
| 2 | 1번에서 몸 전체가 살짝 위로 튀어 오름, 머리카락이 살짝 뒤따라 늦게 움직임 |
| 3 | 가장 높은 지점, 고개를 살짝 오른쪽으로 갸웃 |
| 4 | 다시 내려옴(2번과 비슷한 높이) |
| 5 | 1번 높이, 볼이 살짝 발그레 |
| 6 | 5번에서 반짝이 효과(작은 별 1~2개)가 머리 옆에 |

```
기준 이미지와 같은 캐릭터·구도로 happy(기쁨) 표정 6장을 만들어 줘. 신나서 몸이 통통 튀는 반복 동작이야.
먼저 1번(초승달 눈웃음 + 크게 벌린 입)을 그려 주고, 이후 장은 바로 앞 장을 바탕으로 아래만 바꿔.
- 2번: 몸이 살짝 위로 튀어 오름, 머리카락은 살짝 늦게 따라옴
- 3번: 가장 높은 지점, 고개를 살짝 갸웃
- 4번: 다시 내려오는 중
- 5번: 처음 높이, 볼이 살짝 발그레
- 6번: 5번에 작은 반짝이 별 1~2개가 머리 옆에
위아래 움직임은 크지 않게(머리 높이의 5% 이내).
```

### sad(슬픔·막막함) · 그림 6장 · 반복(0.75초)

"헬프 미… 뭘 해야 하는 거야…" 같은 막막한 순간, 그리고 함정에 쓰러졌을 때도 이 표정을 씁니다. 너무 무겁지 않게, 시무룩한 코믹함입니다.

| 장 | 내용 |
|---|---|
| 1 | 팔자 눈썹, 처진 눈, 입꼬리 내려감, 어깨 처짐 |
| 2 | 1번에서 눈가에 눈물 방울이 맺힘 |
| 3 | 훌쩍: 어깨가 살짝 들썩 위로 |
| 4 | 다시 처짐, 눈물이 볼로 한 줄 |
| 5 | 1번 자세, 머리 위 옆에 작은 먹구름(또는 세로줄 우울 효과) |
| 6 | 5번에서 고개를 살짝 더 숙임 |

```
기준 이미지와 같은 캐릭터·구도로 sad(시무룩·막막함) 표정 6장을 만들어 줘. 무겁지 않고 코믹하게 시무룩한 느낌의 반복 동작이야.
먼저 1번(팔자 눈썹 + 처진 눈 + 내려간 입꼬리 + 처진 어깨)을 그리고, 이후 장은 바로 앞 장을 바탕으로 아래만 바꿔.
- 2번: 눈가에 눈물 방울이 맺힘
- 3번: 훌쩍이며 어깨가 살짝 들썩
- 4번: 어깨가 다시 처지고 눈물이 볼로 한 줄
- 5번: 머리 옆에 작은 먹구름(또는 만화식 세로줄 우울 효과)
- 6번: 고개를 조금 더 숙임
```

### angry(화남) · 그림 4장 · 반복(0.5초)

"아니 나도 안다고!! 훈수 그만!!" 시청자 훈수에 발끈한 순간. 무섭지 않고 귀엽게 씩씩대는 느낌입니다.

| 장 | 내용 |
|---|---|
| 1 | 찌푸린 눈썹(안쪽이 내려감), 볼을 부풀림, 입을 앙 다묾 |
| 2 | 1번에서 몸이 왼쪽으로 1~2px 떨림, 이마 옆에 만화식 분노 마크(💢) |
| 3 | 몸이 오른쪽으로 1~2px 떨림, 머리 위로 김이 '퓨' 하고 남 |
| 4 | 1번 위치, 분노 마크가 살짝 커짐 |

```
기준 이미지와 같은 캐릭터·구도로 angry(발끈) 표정 4장을 만들어 줘. 무섭지 않고 귀엽게 씩씩대며 부들부들 떠는 반복 동작이야.
먼저 1번(찌푸린 눈썹 + 볼 부풀림 + 앙 다문 입)을 그리고, 이후 장은 바로 앞 장을 바탕으로 아래만 바꿔.
- 2번: 몸이 아주 조금 왼쪽으로 떨림, 이마 옆에 만화식 분노 마크
- 3번: 몸이 아주 조금 오른쪽으로 떨림, 머리 위로 김이 피어오름
- 4번: 처음 위치, 분노 마크가 살짝 커짐
```

### shout(놀람·소리침) · 그림 4장 · 한 번(0.5초) 후 마지막 장 유지

"왓츠 댓?!" 무언가를 발견하거나 깜짝 놀란 순간. 다음 스테이지에 도착한 첫마디에도 씁니다. **마지막 장이 3~4초 동안 멈춰 보이므로 4번이 가장 잘 그려져야 합니다.**

| 장 | 내용 |
|---|---|
| 1 | 놀라기 직전: 눈이 살짝 커지기 시작, 입 살짝 벌어짐 |
| 2 | 몸이 뒤로 움찔(살짝 작아짐), 눈 동그랗게 |
| 3 | 앞으로 튀어나오듯 몸이 커짐, 머리카락이 쭈뼛 섬, 입을 크게 벌림 |
| 4 | 최종 포즈: 눈 크게 뜨고 입 크게 벌려 소리치는 얼굴, 머리 옆에 놀람 표시(❗ 모양 선) |

```
기준 이미지와 같은 캐릭터·구도로 shout(깜짝 놀라 소리침) 표정 4장을 만들어 줘. 한 번만 재생하고 마지막 장에서 몇 초간 멈추는 동작이라, 4번이 가장 완성도 있게 보여야 해.
먼저 4번(최종 포즈: 눈을 동그랗게 크게 뜨고 입을 크게 벌려 소리치는 얼굴, 머리카락이 살짝 쭈뼛, 머리 옆에 만화식 놀람 선)을 그리고, 그다음 4번을 바탕으로 1~3번을 거꾸로 만들어 줘.
- 1번: 놀라기 직전, 눈이 살짝 커지고 입이 살짝 벌어짐
- 2번: 몸이 뒤로 움찔, 눈이 동그래짐
- 3번: 앞으로 튀어나오듯, 입을 크게 벌리기 시작
```

### think(채팅 읽는 중) · 그림 6장 · 반복(0.75초)

AI 답을 기다리는 동안 나오는 표정이고, 이때는 말풍선이 없습니다. 화면 오른쪽에 있는 **채팅창을 읽는 모습**입니다.

| 장 | 내용 |
|---|---|
| 1 | 시선을 화면 오른쪽(채팅창 쪽)으로, 입은 작게 "음~" |
| 2 | 눈동자가 오른쪽 위로(위쪽 채팅을 읽음) |
| 3 | 눈동자가 오른쪽 아래로(아래쪽 채팅을 읽음) |
| 4 | 손가락을 턱에 댐, 고개를 살짝 갸웃 |
| 5 | 4번 자세에서 눈을 한 번 깜빡(반쯤 감음) |
| 6 | 4번 자세, 머리 옆에 작은 물음표나 생각 점(…) |

```
기준 이미지와 같은 캐릭터·구도로 think(채팅 읽는 중) 표정 6장을 만들어 줘. 화면 오른쪽에 있는 채팅창을 읽으며 생각하는 반복 동작이야.
먼저 1번(시선을 오른쪽으로 돌리고 입을 작게 오므린 "음~" 표정)을 그리고, 이후 장은 바로 앞 장을 바탕으로 아래만 바꿔.
- 2번: 눈동자가 오른쪽 위로
- 3번: 눈동자가 오른쪽 아래로
- 4번: 손가락을 턱에 대고 고개를 살짝 갸웃
- 5번: 4번 자세에서 눈을 반쯤 감음(깜빡임)
- 6번: 4번 자세, 머리 옆에 작은 물음표나 생각 점(…)
```

## 4. 받은 뒤 확인할 것

- 장마다 캐릭터 위치·크기가 어긋나지 않았는지(넘겨 볼 때 출렁이면 다시 요청)
- 머리 색이 #D3E7A5에서 크게 벗어나지 않았는지(채팅창의 한별 대사 색과 맞춤)
- 배경이 진짜 투명인지(체크무늬 그림이 배경에 그려져 나오는 경우가 있음)
- 입 위치가 그림마다 크게 다르면 말풍선 꼬리 위치(`js/ui.js`의 `MOUTH`)를 맞춰야 하므로 알려 주기

## 5. 게임에 넣기 (2026-11-23 반영)

- 원본: `assets/streamer/<감정>/<감정>N.png` (1024×1536, 장당 약 1.6MB, 합계 42MB)
- 게임용: `assets/sprites/<감정>N.webp` (500×600, 장당 약 45KB, 합계 1.2MB) + 방송 정보 프로필 사진 `avatar.webp`(normal1에서 눈과 머리카락만, 128×128)
- 만드는 법: 개발 서버(`python tools/serve.py 8080`)를 켜고 `http://localhost:8080/tools/sprites.html` → `변환해서 저장`. 원본을 바꾸거나 장을 추가하면 다시 누른다.
  - 위 20%를 잘라 5:6으로 맞추고, 몸이 살짝 비쳐 보이던 부분(알파 250 안팎)을 불투명하게 만든다.
  - angry는 좌우로 흔들리는 폭이 커서(2번 -40px, 3번 +17px) 절반 정도로 줄였다(`SHIFT`). 더 줄이거나 원래대로 하려면 `tools/sprites.html`의 `SHIFT`를 고친다.
  - 프로필 사진 자르는 위치는 `AVATAR`.
- 재생 설정: `js/ui.js`의 `SPRITES`
  - 장 수 `frames`: normal 4 · happy 6 · sad 6 · angry 4 · shout 4 · think 3
  - 재생 순서 `seq`: normal은 가만히 있다가 가끔 숨 쉬기(2)·눈 깜빡임(3→4→3), think는 오른쪽을 보다가 가끔 깜빡임(2→3→2). 나머지는 1~N 반복
  - shout는 한 번 재생 후 마지막 장 유지(`once`)
- 처음 지침과 달라진 점(제작자 결정)
  - sad5·sad6: 먹구름 없이 제작
  - think: 6장 → 3장(1: 채팅창 쪽을 보며 "음~", 2: 반쯤 감음, 3: 완전히 감음)
