## 1. 인트로 화면

### 1-1. 목적
- 페이지를 열자마자 방송(AI·시청자·타이머)이 시작되지 않게 한다. 플레이어가 준비됐을 때 직접 시작한다.
- 게임의 정체(시청자가 되어 AI 스트리머를 훈수하는 게임)를 첫 화면에서 한 번에 알린다.
- **덤:** 브라우저는 사용자가 한 번 클릭하기 전에는 소리를 막는다. "게임 시작" 클릭이 소리를 켜는 계기가 된다.

### 1-2. 흐름
```
페이지 열기 → [인트로] → "게임 시작" 클릭 → (짧은 전환) → 방송 화면 → 플레이 가이드 첫 카드
                 │
                 └ 🔊 소리 설정(3장)
```
- 인트로가 떠 있는 동안 게임은 멈춰 있다(AI 호출 없음, 시청자 채팅·타이머 멈춤). 지금의 튜토리얼 창과 같은 일시정지를 쓴다.
- 시작하면 지금처럼 스테이지 1과 플레이 가이드 첫 카드가 나온다.

### 1-3. 화면 구성(확정)
| 요소 | 내용 |
|---|---|
| 배경 | ✅ **일러스트**: 1인칭 시점으로 한별의 방송을 보고 있는 시청자(플레이어). 데스크톱, 키보드 위 양손, 모니터에 한별 방송과 채팅창. 16:9. 프롬프트는 1-6 |
| 로고 | ✅ 화면 **왼쪽**에 `assets/logo/logo_ko.png` (웹용으로 줄여 WebP 변환: 1.2MB → 약 100KB) |
| 시작 버튼 | ✅ **"게임 시작"** (로고 아래) |
| 한 줄 소개·보조 안내 | ✅ **넣지 않음** |
| 소리 설정 | 🔊 버튼은 위쪽 바에 이미 있음. 인트로에는 따로 두지 않음(아래 3장, ❓ 필요하면 오른쪽 위 작게) |
| 탭 아이콘 | `assets/logo/icon.png` → 파비콘(작게 줄여서) |

레이아웃(가로 화면 기준):
```
┌───────────────────────────────────────────────┐
│                                               │
│   [logo_ko]            (배경 일러스트:          │
│                         1인칭: 키보드 위 양손,     │
│   [ 게임 시작 ]           모니터 속 한별 방송·채팅)  │
│                                               │
└───────────────────────────────────────────────┘
```
- 로고가 놓이는 왼쪽은 일러스트에서 비워 두거나 어둡게 그라데이션을 깔아 글자가 묻히지 않게 한다.
- 세로·좁은 화면: 로고와 버튼을 가운데 아래로 모으고 일러스트는 잘라서 채운다.

### 1-4. 정할 것 ❓
1. ~~배경~~ → 일러스트(확정). 일러스트가 나오기 전까지는 어두운 그라데이션 임시 배경으로 개발한다.
2. ~~문구~~ → 소개 없음, 버튼 "게임 시작"(확정)
3. 인트로에 스테이지 선택을 둘지(포트폴리오 심사자가 원하는 스테이지로 바로 가기). 기본은 **두지 않음**(1부터 순서대로)
4. 스테이지를 깨고 새로고침했을 때 이어 하기를 둘지. 기본은 **두지 않음**

### 1-5. 개발 메모
- 개발 모드(`localhost`, `?dev`)에서는 `?intro=off`로 건너뛸 수 있게 한다(테스트용).
- 인트로는 배포 모드·개발 모드 모두 기본으로 나온다.

### 1-6. 배경 일러스트 생성 프롬프트
**의도:** 첫 화면에서 플레이어가 "나는 시청자"라고 느끼게 한다. 1인칭 시점, 내 책상, 내 손, 모니터 속 한별 방송.

| 항목 | 내용 |
|---|---|
| 시점 | 1인칭. 책상 앞에 앉은 시청자의 눈높이. 화면 아래쪽에 양손이 키보드 위에 올라가 있다 |
| 장소 | 늦은 밤 집 데스크톱 책상(스탠드 조명, 모니터 빛이 손과 키보드를 비춤) |
| 모니터 | 방송 플랫폼 화면: 왼쪽 큰 영역에 한별(웹캠 얼굴 + 뒤로 게임 화면), 오른쪽 세로 채팅창(닉네임 색 줄들, 노란 후원 칸 하나) |
| 한별 | 연두색 곱슬 단발, 바보털 하나, 연두 눈, 흰 셔츠 + 아이보리 니트 카디건(초록 줄·리본·엠블럼). `assets/sprites/normal1.webp` 참고 |
| 구도 | 16:9(1920×1080 이상). **모니터는 화면 오른쪽 60%**, 왼쪽 40%는 어두운 방(벽·그림자)으로 비워 로고·"게임 시작" 버튼 자리로 쓴다 |
| 그림체 | 스프라이트와 같은 깔끔한 애니메이션 일러스트, 부드러운 셀 채색 |
| 피할 것 | 글자·로고·실제 플랫폼 상표, 손가락 수 오류, 화면 왼쪽에 밝은 물건 |

**프롬프트(영문, 이미지 생성기용):**
```
First-person POV illustration of a viewer sitting at a home desktop computer late at night, watching a live stream.
Both of the viewer's hands rest on a mechanical keyboard at the bottom of the frame, lit by the monitor glow.
The monitor is placed on the right 60% of the image and shows a live streaming page: on the left of the screen a cute
anime streamer (short fluffy pale-green hair with a single ahoge, light green eyes, white collared shirt under an ivory
knit cardigan with green trim, a green ribbon and a small emblem) smiling at the camera in a webcam frame over a
3D puzzle game scene; on the right of the screen a vertical live chat column with colorful nickname lines and one
highlighted yellow donation message. Cozy dark room, desk lamp, soft warm light, blue monitor light.

Clean anime illustration style, soft cel shading, high detail, 16:9 aspect ratio, 1920x1080.
No text, no letters, no logos, no watermark, correct hands with five fingers.
```
- 결과물: `assets/intro/bg.webp`(웹용 압축, 약 300KB 이하)로 넣는다. 나오기 전까지는 어두운 그라데이션 임시 배경.
- 모니터 속 채팅 글자는 생성기가 깨뜨리기 쉬워 "글자 없음"으로 두었다. 필요하면 나중에 실제 채팅 줄을 HTML로 얹을 수 있다.

## 2. 플레이 가이드 다시 보기 버튼 (확정·구현됨 2026-11-24)

### 2-1. 목적
- 플레이 가이드 카드를 실수로 닫아도 다시 볼 수 있게 한다.

### 2-2. 동작
- 버튼을 누르면 플레이 가이드 창이 열리고 게임이 멈춘다(지금 가이드 창과 같음). `확인`으로 닫는다.
- 보여 주는 카드: ✅ **지금 스테이지까지 오는 동안 본 카드만**. 예: 스테이지 2에서 누르면 스테이지 1·2에서 본 카드.
- 순서는 본 순서. 마지막으로 본 카드부터 열고 `◀ 이전`·`다음 ▶`로 넘긴다.
- 아직 못 본 카드(예: 처음 죽었을 때 나오는 카드)는 보여 주지 않는다(스포일러 방지).
- ✅ 새 카드 알림 점(●)은 **띄우지 않는다**. 대신 버튼 외곽선을 처음부터 **노란색**(강조색)으로 해서 눈에 띄게 한다.

### 2-3. 버튼
- ✅ 위치: 방송 정보 줄, `♡ 팔로우` 버튼 **왼쪽**. 이름 `📖 플레이 가이드`.
- ✅ 단축키 없음.
- 코드: `index.html` `#guideReplay`, `js/tutorial.js` `replay()`, 스타일 `.guide-replay`

## 3. 소리 설정(음량)

### 3-1. 답: 환경설정 창이 하나 필요하다
지금 `⚙ 설정`은 API 키를 넣는 개발용 창이라 배포 화면에서는 숨겨진다. 그래서 **플레이어용 소리 설정**을 따로 둔다. 크게 만들 필요는 없고, 버튼 하나와 작은 팝오버면 된다.

### 3-2. 구성(제안)
- 위쪽 바 오른쪽에 `🔊` 버튼 → 누르면 아래로 작은 패널이 펼쳐진다(게임은 멈추지 않는다).
- 슬라이더 3개 + 전체 음소거:
  | 항목 | 들어가는 소리 |
  |---|---|
  | 효과음 | 문·버튼·레버·아이템·채팅·후원·클리어 등 |
  | 환경음 | 탈출로의 돌가루·자갈 떨어지는 소리, 바위·통 굴러오는 소리 |
  | 한별 목소리 | 말풍선 웅얼거림(`voice.babble`), 질문할 때 "응?" |
- 값은 이 브라우저에 저장한다(다음에 열어도 유지). 기본값은 ✅ **셋 다 100%**.
- 인트로 화면에도 같은 `🔊` 버튼을 둔다.

### 3-3. 정할 것 ❓
- ~~기본 음량~~ → 100%(확정)
- 음소거를 버튼 하나로 할지(아이콘을 누르면 음소거, 길게 누르거나 옆 화살표로 슬라이더)
