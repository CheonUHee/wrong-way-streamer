# 게임 로고 제작 지침(이미지 생성 AI 요청용)

사이트 첫 화면(인트로)에 들어갈 타이틀 로고입니다. `streamer_sprites.md`와 같은 방식으로,
아래 `공통 지침`을 첫 메시지에 붙여 넣고 그다음 버전별 블록을 하나씩 요청하세요.

---

## 0. 디자인 방향(왜 이렇게 정했나)

| 게임의 특징 | 로고에 옮기는 방법 |
|---|---|
| 시청자가 채팅으로 스트리머를 조종한다 | 제목을 **채팅 말풍선** 안에 넣는다. 제목 자체가 시청자가 친 채팅처럼 보이게 |
| 스트리머가 엉뚱한 데로 간다(제목의 핵심 농담) | 글자 줄을 살짝 기울여 "삐끗한" 느낌. (꺾인 화살표는 시안에서 넣었다가 뺐다 → 4번 참고) |
| 인터넷 방송 | 빨간 **LIVE 배지**, 녹화 점 같은 방송 UI 조각 |
| 덤벙대는 4차원 스트리머 한별 | 땀방울, "!?" 같은 만화 효과. 무섭지 않고 귀엽고 시끄러운 톤 |
| 팝아트 | 굵은 검은 외곽선, 벤데이 망점, 방사형 집중선, 강한 원색 대비, 글자 뒤에 어긋난 그림자 |

**색**: 게임 UI 색과 맞춰 둡니다. 인트로에서 로고와 게임 화면이 같은 세계로 보이게 하기 위해서입니다.

- 노랑 `#FFE14A`(게임 강조색, 로고 주색)
- 빨강 `#FF4D5E`(LIVE 배지, 경고 화살표)
- 하늘 `#6FD3FF`(시청자 채팅 색, 말풍선)
- 연두 `#D3E7A5`(한별 머리 색, 포인트로만)
- 검정 `#0E0F13`(외곽선, 배경)

**주의: 한글 글자는 AI가 자주 틀립니다.** 받침이 빠지거나 없는 글자가 섞이기 쉽습니다.
그래서 이미지 AI로는 **구도·색·장식을 정하는 시안**을 뽑고, 최종 글자는 받은 시안을 보고
웹폰트(예: 굵은 한글 디스플레이 폰트)로 다시 얹거나 SVG로 다시 그리는 것을 권합니다.
영문 로고는 AI가 비교적 정확하게 씁니다.

## 1. 공통 지침(첫 메시지에 붙여 넣기)

```
웹 게임의 타이틀 로고를 만들 거야. 아래 조건을 모든 시안에 똑같이 지켜 줘.

[게임 소개]
- 제목: 「스트리머님, 거기 아닌데요!」 / 영문 「Wrong Way, Streamer!」
- 장르: 시청자가 채팅으로 AI 스트리머에게 길을 알려 주는 3D 퍼즐 게임.
- 핵심 농담: 호기심 많고 덤벙대는 스트리머가 시청자 말을 듣다가도 자꾸 엉뚱한 방향으로 간다.
  시청자는 채팅창에서 "거기 아니에요!"라고 외치게 된다.
- 분위기: 밝고 시끄럽고 귀여운 코미디. 공포·폭력 느낌은 없음.

[스타일: 팝아트]
- 1960년대 팝아트·미국 만화 표지 느낌. 굵고 균일한 검은 외곽선.
- 벤데이 망점(halftone dots) 질감을 배경이나 글자 그림자 일부에만 사용.
- 글자는 아주 굵은 둥근 고딕 계열, 두꺼운 외곽선 + 오른쪽 아래로 어긋난 단색 그림자(입체 블록 느낌).
- 평면 색 위주. 그라데이션·광택·3D 렌더링·사진 질감은 쓰지 않음.

[색: 이 다섯 가지만 사용]
- 주색 노랑 #FFE14A, 빨강 #FF4D5E, 하늘 #6FD3FF, 연두 #D3E7A5(포인트만), 외곽선·어두운 면 #0E0F13.
- 흰색은 하이라이트와 말풍선 안쪽에만.

[반드시 들어갈 모티프]
1. 채팅 말풍선: 제목이 시청자가 친 채팅처럼 말풍선 안에 들어감. 말풍선 꼬리는 아래 방향.
2. 꺾인 화살표: 한쪽으로 가다가 엉뚱한 방향으로 휘어 버린 굵은 화살표. 제목 뒤를 지나가거나 글자에 걸쳐 있음.
3. 방송 표시: 작은 빨간 "● LIVE" 배지를 말풍선 모서리에.
4. 만화 효과: "!?" 기호, 땀방울, 짧은 움직임 선 중 1~2개만. 과하지 않게.

[구도·형식]
- 가로형 로고, 비율 약 2:1. 로고만 있고 주변은 비워 둠.
- 배경은 투명(PNG). 투명이 어려우면 단색 #0E0F13.
- 작게 줄여도(가로 400px) 제목이 읽혀야 함. 장식이 글자를 가리지 않게.
- 캐릭터(사람)는 그리지 않음. 글자와 기호만으로 구성.
- 제목 외의 글자(가짜 영어, 의미 없는 문구)는 넣지 않음.
```

## 2. 버전별 요청

### 2-1. 한글 메인 로고

```
위 조건으로 한글 메인 로고를 그려 줘.
- 글자는 정확히 「스트리머님, 거기 아닌데요!」. 두 줄로 나눔: 윗줄 「스트리머님,」 아랫줄 「거기 아닌데요!」.
- 아랫줄 「거기 아닌데요!」를 더 크게, 노랑 #FFE14A로. 윗줄은 하늘 #6FD3FF로 조금 작게.
- 아랫줄은 오른쪽 위로 5도쯤 기울여 "삐끗한" 느낌.
- 「!」는 빨강 #FF4D5E로 크게, 살짝 튀어 오르듯.
- 아래 작은 글씨로 「Wrong Way, Streamer!」를 흰색으로 한 줄.
- 한글 글자 모양을 하나하나 정확히 지켜 줘. 없는 글자나 받침이 빠진 글자가 생기면 안 돼.
```

### 2-2. 영문 로고(해외용·공유 썸네일용)

```
위 조건으로 영문 로고를 그려 줘.
- 글자는 정확히 「WRONG WAY, STREAMER!」. 두 줄: 윗줄 「WRONG WAY,」 아랫줄 「STREAMER!」.
- 「WRONG WAY」의 W 또는 Y 옆에서 꺾인 화살표가 출발해 엉뚱한 방향으로 휘어 나감.
- 「STREAMER!」는 노랑, 「WRONG WAY,」는 빨강.
- 아래 작은 글씨로 「스트리머님, 거기 아닌데요!」 한 줄은 넣지 말고 비워 둬(한글은 나중에 직접 얹음).
```

### 2-3. 아이콘 버전(파비콘·로딩 화면용)

```
위 조건에서 글자를 빼고 정사각형 아이콘으로 만들어 줘.
- 노랑 채팅 말풍선 안에 빨간 꺾인 화살표 하나, 말풍선 모서리에 작은 "!?".
- 32×32로 줄여도 모양이 알아보이게 단순하게.
```

## 3. 고칠 때 쓰는 문장

시안이 마음에 들면 처음부터 다시 그리게 하지 말고, 받은 그림을 첨부해 한 가지씩 고칩니다.

- 너무 복잡할 때: `장식을 절반으로 줄이고 제목 글자를 더 크게.`
- 너무 진지할 때: `글자를 조금 통통 튀게, 줄마다 기울기를 다르게 해서 더 장난스럽게.`
- 팝아트 느낌이 약할 때: `외곽선을 더 굵게, 말풍선 배경에 큰 망점과 방사형 집중선을 넣어 줘.`
- 화살표가 안 보일 때: `꺾인 화살표를 빨강으로 더 굵게, 글자 뒤가 아니라 앞을 지나가게.`
- 색이 벗어날 때: `지정한 다섯 가지 색 외의 색은 모두 빼 줘.`

### 한글 로고: 첫 시안에서 고친 점

- 「스트리머님,」: 하늘색 → 연두 `#D3E7A5`(한별 머리 색). 입체 부분은 노랑 → 검정으로 통일.
- 「거기 아닌데요!」: 입체 부분 노랑 → 검정으로 통일.
  - 이유: 입체 부분까지 노랑이면 글자와 그림자가 한 덩어리로 뭉개진다. 팝아트의 굵은 검은 외곽선과 같은 색으로 맞춰 글자 윤곽을 또렷하게 했다.
- 꺾인 화살표: 삭제. 화살표가 지나가던 자리는 말풍선 외곽선이 끊기지 않고 이어지게 마감.
  - 이유: 화살표가 글자와 말풍선 위로 지나가며 제목을 읽기 어렵게 만들었다. "엉뚱한 방향"은 기울어진 글자 줄로 충분히 전달된다.

### 아이콘: 한글 로고를 기준으로 다시 설계

- 글자 없이 정사각형 기준. 32×32로 줄여도 알아보이게 단순하게.
- 구성: 흰 말풍선(검은 외곽선, 아래 꼬리) + 왼쪽 위 빨간 「● LIVE」 배지 + 중앙의 「?!」.
- 「?!」는 로고 글자와 같은 팝아트 입체(검은 외곽선 + 검은 입체 그림자).
  - `?`: 연두 `#D3E7A5`. 오른쪽으로 살짝 기울임. 몸통과 점 사이 약 5px.
  - `!`: 노랑 `#FDDA42`(로고의 「거기 아닌데요!」와 같은 노랑). 오른쪽으로 살짝 기울임. 몸통과 점 사이 약 5px.
  - 두 색 조합 이유: 로고의 윗줄(연두)·아랫줄(노랑) 색을 그대로 가져와, 아이콘만 봐도 로고와 같은 세트로 보이게.

> 색 메모: 실제 노랑은 처음 정한 `#FFE14A`보다 조금 진한 `#FDDA42` 계열로 확정됐다.
> 인트로 화면을 만들 때 버튼·강조색을 로고와 맞추려면 `#FDDA42`를 쓴다.

## 5. 받은 뒤 처리

- 저장 위치: `assets/logo/` (예: `logo_ko.png`, `logo_en.png`, `icon.png`)
- 한글 로고는 시안의 구도·색을 따라 웹폰트나 SVG로 글자를 다시 얹는 것을 권함(0번 주의 참고).
- 인트로 화면에서 쓸 움직임(나중에 구현): 말풍선이 "톡" 튀어나오고 → 화살표가 그려지다 엉뚱하게 꺾이고 → LIVE 배지가 깜빡이는 순서.
