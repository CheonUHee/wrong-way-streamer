# 효과음 목록

## 제작 결과 (2026-11-24)

메모의 GOOD 항목을 만들었다(X 항목은 뺐다). 톤은 레트로 전자음 없이 사실적인 소리 위주.

- 코드: `js/sfx.js` (소리 목록 `SOUNDS`), 녹음 파일: `assets/sfx/` (Kenney CC0, 출처는 `assets/sfx/README.md`)
- 들어 보기: 테스트 모드 → `🔊 소리 듣기`에서 하나씩 재생. 클리어 팡파르는 B안으로 확정
- 음량: 위쪽 바 `🔊` → 효과음 · 환경음 · 한별 목소리 · 모두 끄기(이 브라우저에 저장)
- 브라우저는 첫 클릭 전에는 소리를 막는다. 인트로 화면이 생기면 그 클릭에서 켜진다(docs/specs/intro-guide-sound.md)

---


게임 안의 요소마다 넣을 만한 효과음 후보입니다. 맨 오른쪽 `메모` 칸에 고려할 점을 적어 주세요.

- 방식
  - **합성**: Web Audio로 코드에서 만듭니다(파일 없음).
  - **에셋**: 무료 CC0 효과음을 받아 씁니다(Kenney, Freesound CC0 등).
  - **둘 다**: 합성으로 먼저 넣고, 나중에 에셋으로 바꿔도 됩니다.
- 우선순위
  - ★★★: 없으면 허전함.
  - ★★: 있으면 확실히 좋아짐.
  - ★: 여유 있을 때.
- 소리를 내는 곳(코드)은 참고용입니다. 나중에 `js/sfx.js`의 `play('id')` 한 줄로 연결합니다.

## 정해 주시면 좋은 것

- 전체 톤: 귀여운 레트로 전자음과 사실적인 소리 중 어느 쪽으로 할지, 아니면 섞을지
- 한별 웅얼거림(`voice.babble`)을 넣을지. 나중에 실제 TTS 목소리를 붙일 계획이 있는지
- 배경음악(BGM)을 넣을지. 이 목록은 효과음만 다룹니다
- 음량 조절을 하나로 할지, 효과음·환경음·한별 목소리로 나눌지
- 채팅 소리가 너무 잦을 때 줄이는 기준(예: 1초에 한 번만)
